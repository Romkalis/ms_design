## Галерея на WordPress

Галерея (`/gallery` и `/gallery/<проект>`) работает на WordPress, остальные страницы остаются статикой.
WordPress стоит в корне сайта рядом со статикой: если файл есть, Apache отдаёт его, иначе запрос уходит в WordPress.

Исходники:
- `src/wp/theme` — тема «Дизайн-Цех». В php-шаблоны при сборке подставляются общие блоки из `src/html/blocks` (шапка, подвал, форма).
- `src/wp/.htaccess` — `.htaccess` для сайта с WordPress (обычный `src/.htaccess` — для чистой статики).

Сборки:
- `npm run build` — чистая статика, как раньше, со статической галереей.
- `npm run build:wp` — статика без страниц галереи + тема в `docs/wp-content/themes/msk-design` + `.htaccess` для WordPress.

### Установка

1. Создать базу MySQL в панели хостинга, установить WordPress в корень сайта.
2. `npm run build:wp` и залить содержимое `docs/` в корень сайта поверх WordPress (`.htaccess` заменится).
3. В админке: «Внешний вид → Темы» → активировать «Дизайн-Цех». При активации ставятся адреса без слэша на конце: `/gallery/tanin-dom`.
4. На тестовом домене: «Настройки → Чтение» → «Попросить поисковые системы не индексировать сайт».
5. «Инструменты → Здоровье сайта → Информация → Медиа»: должен быть GD или Imagick с поддержкой WebP.

### Перенос существующих проектов

Залить на сервер папки `src/html` и `src/img/gallery` с сохранением структуры, например в `~/msk-import/src/html` и `~/msk-import/src/img/gallery`. Затем по SSH из папки сайта:

```
wp msk import-gallery ~/msk-import/src --user=<логин администратора> --dry-run
wp msk import-gallery ~/msk-import/src --user=<логин администратора>
```

Первая команда только показывает, что будет перенесено, и предупреждает о ненайденных файлах. Повторный запуск обновляет проекты и не загружает фото второй раз.

### Как добавить проект

«Галерея → Добавить проект»: название, описание, фото (можно выбрать сразу много, порядок — перетаскиванием), история проекта, справа — раздел(ы), обложка карточки и порядок. Разделы, их порядок и подписи в меню — «Галерея → Разделы».
