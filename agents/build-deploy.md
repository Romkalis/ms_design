# Сборка и деплой

## Команды

| Команда | Результат |
|---|---|
| `npm install` | Зависимости (только локально, без `-g`) |
| `npm run dev` | Dev-сборка в `build/` + локальный сервер с livereload |
| `npm run build` | Чистая статика в `docs/`, со статической галереей и `src/.htaccess` |
| `npm run build:wp` | Статика без `gallery.html` и `gallery/`, тема в `docs/wp-content/themes/msk-design`, `.htaccess` из `src/wp/` |
| `npm run format` | Prettier по `src/` |

`build` и `build:wp` пишут в одну папку `docs/` и стирают её перед сборкой. Задачи — в `gulp/docs.js` и `gulp/wp.js`, режим WordPress включается переменной `BUILD_TARGET=wp` внутри задачи `build:wp`.

WordPress в сборку не входит, ставится на хостинге отдельно.

## Установка на тестовый домен

1. Сохранить и очистить `public_html` сайта `design-96.ru`.
2. Установить WordPress в корень: «Каталог CMS» в панели Timeweb (сам создаст базу) или вручную.
3. `npm run build:wp`, залить содержимое `docs/` в корень поверх WordPress.
4. Активировать тему «Дизайн-Цех», включить «Не индексировать сайт» в «Настройки → Чтение».
5. «Инструменты → Здоровье сайта → Информация → Медиа»: проверить GD/Imagick и поддержку WebP.
6. Включить SSH, проверить `wp --info`, залить `src/html` и `src/img/gallery`, запустить импорт сначала с `--dry-run` (см. [wordpress-gallery.md](wordpress-gallery.md)).

Если `docs/` залита раньше WordPress, мастер установки открывается по `/wp-admin/install.php`: на `/` отдаётся статическая главная.

## Перенос на боевой сайт

Только после проверки на тесте и с разрешения владельца:
- бэкап файлов боевого сайта;
- WordPress в корень боевого сайта, сборка `build:wp`, тема, импорт;
- в `robots.txt` добавить `Sitemap: …/wp-sitemap.xml`;
- проверить, что открываются главная, цены, контакты, форма заявки, `/gallery`, все страницы проектов, а старые `*.html` перенаправляются.
