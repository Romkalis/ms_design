# Галерея на WordPress

Задача: заказчик сам добавляет в разделы галереи карточки проектов и страницы за ними (фото, заголовок, описание). Без платных плагинов.

## Схема

WordPress стоит в корне сайта рядом со статикой. `src/wp/.htaccess`:
- `DirectoryIndex index.html index.php` — главная остаётся статической;
- существующий файл (или `<имя>.html`) отдаёт Apache, остальное уходит в WordPress (стандартный блок `# BEGIN WordPress`);
- старые `/gallery.html` и `/gallery/<slug>.html` перенаправляются 301 на адреса без `.html`.

Постоянные ссылки — `/%postname%` (без слэша на конце), ставятся при активации темы. Архив проектов — `/gallery`, проект — `/gallery/<slug>`.

## Модель данных

Тип записей `project` (`inc/content-types.php`), классический редактор:

| Что | Где хранится |
|---|---|
| Название (h1) | `post_title` |
| Адрес | `post_name` |
| История проекта (текст под фото) | `post_content` |
| Обложка карточки | миниатюра записи; если нет — первое фото галереи |
| Порядок карточки | `menu_order` (по возрастанию) |
| Описание под заголовком | `_msk_lead` |
| Фото проекта | `_msk_gallery` — ID вложений через запятую, в порядке показа |
| Заголовок карточки | `_msk_card_title`, если пусто — название |
| Текст карточки | `_msk_card_text`, если пусто — описание |
| SEO | `_msk_seo_title`, `_msk_seo_description`, если пусто — генерируются |

Разделы — таксономия `project_section` (галочки, своих страниц нет). Мета раздела: `msk_order` (порядок на странице), `msk_nav_label` (подпись в меню над разделами), `msk_show_card_text` (показывать текст на карточках). Проект может быть в нескольких разделах, обложка у него одна.

## Файлы темы (`src/wp/theme`)

| Файл | Назначение |
|---|---|
| `functions.php` | Подключение модулей, поддержка темы, постоянные ссылки при активации |
| `header.php`, `footer.php` | `<head>`, шапка, подвал, модалка, cookie, скрипт. Блоки из `src/html/blocks` подставляются при сборке |
| `archive-project.php` | `/gallery`: меню разделов, разделы со слайдерами карточек, форма заявки |
| `single-project.php` | Страница проекта |
| `index.php`, `404.php` | Запасной шаблон и «не найдено» |
| `inc/template-helpers.php` | Функции получения данных проекта и разделов для шаблонов |
| `inc/admin-project.php` | Поля проекта, metabox галереи (wp.media + перетаскивание), колонки списка |
| `inc/admin-sections.php` | Поля раздела |
| `inc/media.php` | Порог 2000px, качество 82, копии jpg/png в webp, лишние размеры не создаются |
| `inc/seo.php` | title, description, canonical, Open Graph для галереи |
| `inc/cleanup.php` | Убирает лишнее из `<head>`, скрывает админ-панель на сайте, редиректит страницы авторов и вложений |
| `inc/cli-import.php` | Команда WP-CLI для переноса статической галереи |
| `assets/admin-gallery.js`, `assets/admin.css` | Интерфейс галереи в админке |

## Импорт существующих проектов

```
wp msk import-gallery <путь к src> --user=<админ> [--dry-run]
```

Читает `html/blocks/gallery/gallery__content.html` (разделы, карточки, обложки) и `html/gallery/<slug>.html` (h1, описание, история, фото, title, description). Фото берёт из `img/…` по путям из вёрстки. Нужны только папки `src/html` и `src/img/gallery`.

Повторный запуск безопасен: проекты ищутся по slug, разделы — по slug раздела, фото — по мета `_msk_source` (исходный путь), так что второй раз они не загружаются. Порядок проектов — порядок первого появления на странице галереи.

## Ограничения

- Разная обложка одного проекта в разных разделах не поддерживается.
- Карта сайта `sitemap.xml` статическая. Новые проекты есть только в `/wp-sitemap.xml` WordPress.
- Типограф gulp к текстам из WordPress не применяется.
