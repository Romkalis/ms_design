# Вводные для агентов

Папка для ИИ-агентов и разработчиков, которые подключаются к проекту. Прочитай файлы по порядку, прежде чем менять код.

| Файл | Что внутри |
|---|---|
| [rules.md](rules.md) | Правила работы: что можно делать самому, что только после подтверждения, стиль кода |
| [project.md](project.md) | Что за сайт, стек, структура репозитория, как устроены страницы |
| [wordpress-gallery.md](wordpress-gallery.md) | Галерея на WordPress: модель данных, шаблоны, админка, импорт |
| [build-deploy.md](build-deploy.md) | Сборки, хостинг, `.htaccess`, установка и деплой |
| [status.md](status.md) | Что сделано, что дальше, принятые решения и риски |

## Коротко

- Сайт студии дизайна интерьеров «Дизайн-Цех Ольги Бараевой»: статический HTML, собирается gulp из `src/` в `docs/`.
- Галерея проектов (`/gallery`, `/gallery/<проект>`) переводится на WordPress, чтобы заказчик сам добавлял проекты с фото. Остальные страницы остаются статикой.
- Тема WordPress — `src/wp/theme`, собирается командой `npm run build:wp`.
- Боевой сайт — `дизайн-цех.рф`, тест — `design-96.ru`. На боевом сайте ничего не меняем без явного разрешения.

## Как поддерживать эту папку

После заметных изменений обнови [status.md](status.md), а если поменялась архитектура или процесс — соответствующий файл. Факты, которые видно из кода, сюда не дублируй, достаточно ссылки на файл.
