# Правила работы

## Только после явного подтверждения владельца

- Любые действия на хостинге: загрузка и удаление файлов, создание баз, смена версии PHP, правки в панели Timeweb.
- Всё, что касается боевого сайта `дизайн-цех.рф`. Сначала проверяем на тестовом `design-96.ru`.
- DNS-записи у регистраторов (боевой домен — reg.ru, тестовый — Timeweb).
- Коммиты, пуши, создание PR.
- Удаление фото и проектов в WordPress, запуск импорта без `--dry-run`.

## Нельзя

- Ставить пакеты глобально (`npm i -g …`), чтобы заработала команда. Используй локальные инструменты через npm-скрипты (`npm run dev`, `npm run build`, `npx …`), а если не работает — исправь скрипт или документацию.
- Коммитить новые секреты и выводить существующие в ответах, логах, документации. Известная проблема: пароль SMTP сейчас записан прямо в `src/files/mail.php`, который лежит в git (см. [status.md](status.md)). `src/files/.env` уже в `.gitignore`, переносить секреты нужно туда.
- Переименовывать адреса страниц галереи: опечатка `disctricts` в адресах сохранена ради позиций в поиске.
- Подключать платный ACF Pro. Поля и галерея проекта сделаны своими metabox'ами.

## Стиль кода

- Отступы — табы, форматирование — Prettier по `.prettierrc` (ширина строки 182, PHP с одинарными кавычками).
- Комментарии и тексты интерфейса — на русском, как во всём проекте. Комментарий нужен, когда неочевидно «почему», а не «что».
- HTML-блоки подключаются через `@@include(...)` (gulp-file-include). Общие части (шапка, подвал, форма, аналитика) не копируй, а подключай из `src/html/blocks`.
- В PHP: префикс `msk_` у функций, `MSK_` у констант, мета-ключи проекта с подчёркиванием (`_msk_…`), чтобы не светились в «Произвольных полях». Весь вывод экранируется (`esc_html`, `esc_attr`, `esc_url`).
- Пути к ресурсам в вёрстке абсолютные: `/img/…`, `/css/main.css?v=1.0.1`.

## Проверка

- Локально нет PHP и MySQL, поэтому WordPress проверяется только на тестовом домене. Синтаксис PHP можно проверить парсером из Prettier:
  `npx prettier --plugin=@prettier/plugin-php --parser=php src/wp/theme/inc/<файл>.php > /dev/null`
- После правок темы или вёрстки запусти `npm run build:wp` и убедись, что сборка прошла и в `docs/wp-content/themes/msk-design/*.php` не осталось `@@include`.
- Честно сообщай, что проверено, а что нет.
